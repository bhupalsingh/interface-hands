# Evidence

`example-artifact.json` is a reviewable sample checked into the repository. Run `npm run demo` to produce fresh discovery and replay logs under `evidence/runtime/`.

Before submission, run `npm run discover` with `OPENAI_API_KEY` set. Commit the resulting artifact and redacted discovery log here as `live-artifact.json` and `live-discovery.jsonl`. Then run successful and not-found replays against that artifact and copy the generated logs here. Do not claim the checked-in scripted example is LLM evidence.
